Text Tags

<h1> – <h6>

Definition

Define six levels of section headings, from most important (<h1>) to least important (<h6>). They give a page its outline and are used by screen readers and search engines to understand structure.

Attributes

Attributes of <h1>–<h6>
AttributeRole
idGives the heading a unique identifier, often used as a jump-link target.
classAttaches a CSS class for styling from style.css.

Example

<h1>Main Title</h1>
<h2>Section Title</h2>
<h3>Subsection Title</h3>

Main Title

Section Title

Subsection Title

<p>

Definition

Represents a paragraph of text. Browsers automatically add space before and after each paragraph.

Attributes

Attributes of <p>
AttributeRole
idUniquely identifies the paragraph.
classApplies a CSS class to the paragraph.

Example

<p>This is a simple paragraph of text.</p>

This is a simple paragraph of text.

<strong>

Definition

Marks text with strong importance. Browsers render it in bold by default.

Attributes

Attributes of <strong>
AttributeRole
idUniquely identifies the element.
classApplies a CSS class for styling.

Example

<p>This word is <strong>important</strong>.</p>

This word is important.

<em>

Definition

Marks text with stress emphasis. Browsers render it in italics by default.

Attributes

Attributes of <em>
AttributeRole
idUniquely identifies the element.
classApplies a CSS class for styling.

Example

<p>I <em>really</em> mean it.</p>

I really mean it.

<br>

Definition

Inserts a single line break inside a block of text, without starting a new paragraph. It is a void (self-closing) element.

Attributes

Attributes of <br>
AttributeRole
idUniquely identifies the element.

Example

<p>First line<br>Second line</p>

First line
Second line

<span>

Definition

A generic inline container with no default meaning, used to group text so it can be styled or targeted with CSS/JavaScript.

Attributes

Attributes of <span>
AttributeRole
idUniquely identifies the element.
classApplies a CSS class to style only that piece of text.

Example

<p>My favorite color is <span class="example-result">teal</span>.</p>

My favorite color is teal.

<mark>

Definition

Highlights text that is relevant to the current context, typically shown with a yellow background.

Attributes

Attributes of <mark>
AttributeRole
idUniquely identifies the element.
classApplies a CSS class for styling.

Example

<p>Please <mark>highlight</mark> this part.</p>

Please highlight this part.

<abbr>

Definition

Marks an abbreviation or acronym. The title attribute usually holds the full expansion, shown as a tooltip on hover.

Attributes

Attributes of <abbr>
AttributeRole
titleProvides the full text the abbreviation stands for, shown as a tooltip.

Example

<abbr title="HyperText Markup Language">HTML</abbr>

HTML

<blockquote>

Definition

Marks a block of text quoted from another source, usually rendered with indentation.

Attributes

Attributes of <blockquote>
AttributeRole
citeA URL pointing to the source of the quotation.

Example

<blockquote cite="https://example.com">
  The only way to do great work is to love what you do.
</blockquote>
The only way to do great work is to love what you do.

<small>

Definition

Represents side comments such as fine print, disclaimers, or legal text, typically rendered in a smaller font size.

Attributes

Attributes of <small>
AttributeRole
idUniquely identifies the element.
classApplies a CSS class for styling.

Example

<p>Price: $9.99 <small>(tax not included)</small></p>

Price: $9.99 (tax not included)
