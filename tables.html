Table Tags

<table>

Definition

The root element that creates a table for displaying tabular data.

Attributes

Attributes of <table>
AttributeRole
idUniquely identifies the table.
classApplies a CSS class to style the table.

Example

<table>
  <tr><td>Row 1</td></tr>
</table>
Row 1

<caption>

Definition

Provides a title or caption for the table, describing what the data represents.

Attributes

Attributes of <caption>
AttributeRole
idUniquely identifies the caption.

Example

<table>
  <caption>Monthly Sales</caption>
  <tr><td>January</td></tr>
</table>
Monthly Sales
January

<thead>

Definition

Groups the header row(s) of a table, separating column titles from the data.

Attributes

Attributes of <thead>
AttributeRole
idUniquely identifies the header group.

Example

<table>
  <thead>
    <tr><th>Name</th></tr>
  </thead>
</table>
Name

<tbody>

Definition

Groups the main body rows of a table, containing the actual data rows.

Attributes

Attributes of <tbody>
AttributeRole
idUniquely identifies the body group.

Example

<table>
  <tbody>
    <tr><td>Anna</td></tr>
  </tbody>
</table>
Anna

<tfoot>

Definition

Groups the footer row(s) of a table, often used for totals or summaries.

Attributes

Attributes of <tfoot>
AttributeRole
idUniquely identifies the footer group.

Example

<table>
  <tfoot>
    <tr><td>Total: $50</td></tr>
  </tfoot>
</table>
Total: $50

<tr>

Definition

Defines a single row of cells within a table.

Attributes

Attributes of <tr>
AttributeRole
idUniquely identifies the row.

Example

<table>
  <tr><td>A</td><td>B</td></tr>
</table>
AB

<th>

Definition

Defines a header cell in a table. Browsers render its content bold and centered by default.

Attributes

Attributes of <th>
AttributeRole
scopeStates whether the header applies to a "col" or a "row".
colspanMakes the header span multiple columns.
rowspanMakes the header span multiple rows.

Example

<table>
  <tr><th scope="col">City</th></tr>
</table>
City

<td>

Definition

Defines a standard data cell within a table row.

Attributes

Attributes of <td>
AttributeRole
colspanMakes the cell span multiple columns.
rowspanMakes the cell span multiple rows.

Example

<table>
  <tr><td colspan="2">Spans two columns</td></tr>
</table>
Spans two columns
