Semantic & Link Tags

<a>

Definition

Creates a hyperlink to another page, a resource, an email address, or a location within the same page.

Attributes

Attributes of <a>
AttributeRole
hrefThe destination URL the link points to.
targetWhere to open the link, e.g. "_blank" for a new tab.
relDescribes the relationship to the target, e.g. "noopener".

Example

<a href="tables.html">Go to Tables page</a>
Go to Tables page

<header>

Definition

Represents introductory content for a page or section, typically containing a heading, logo, or tagline.

Attributes

Attributes of <header>
AttributeRole
idUniquely identifies the header.
classApplies a CSS class for styling.

Example

<header>
  <h1>My Site</h1>
</header>

My Site

<nav>

Definition

Marks a block of navigation links, such as a main menu or breadcrumb trail.

Attributes

Attributes of <nav>
AttributeRole
idUniquely identifies the navigation block.
classApplies a CSS class for styling.

Example

<nav>
  <ul>
    <li><a href="index.html">Home</a></li>
  </ul>
</nav>
  • Home

<main>

Definition

Represents the dominant, unique content of the page. There should be only one visible <main> per page.

Attributes

Attributes of <main>
AttributeRole
idUniquely identifies the main content area.

Example

<main>
  <p>This is the primary content of the page.</p>
</main>

This is the primary content of the page (this whole page's <main> is a live example).

<section>

Definition

Groups a thematic block of content, usually with its own heading, such as a chapter or a tab panel.

Attributes

Attributes of <section>
AttributeRole
idUniquely identifies the section, often used as a link target.

Example

<section>
  <h2>About Us</h2>
  <p>We build websites.</p>
</section>

Every tag block on this page is itself wrapped in a <section>.

<article>

Definition

Represents a self-contained piece of content that could be distributed independently, such as a blog post or news story.

Attributes

Attributes of <article>
AttributeRole
idUniquely identifies the article.

Example

<article>
  <h2>Breaking News</h2>
  <p>Something happened today.</p>
</article>

Breaking News

Something happened today.

<aside>

Definition

Represents content that is tangentially related to the surrounding content, such as a sidebar or a pull quote.

Attributes

Attributes of <aside>
AttributeRole
idUniquely identifies the aside content.

Example

<aside>
  <p>Related: check out our Tables page.</p>
</aside>

<footer>

Definition

Represents footer content for a page or section, typically containing copyright, contact info, or related links.

Attributes

Attributes of <footer>
AttributeRole
idUniquely identifies the footer.

Example

<footer>
  <p>&copy; 2026 My Site</p>
</footer>

See the bottom of this page — it is built with a <footer> element.

<div>

Definition

A generic block-level container with no semantic meaning, used to group elements for layout or styling purposes.

Attributes

Attributes of <div>
AttributeRole
idUniquely identifies the div.
classApplies a CSS class to style the group.

Example

<div class="example-result">
  <p>Grouped content</p>
</div>

Grouped content

<address>

Definition

Provides contact information for the author or owner of a page or article, often rendered in italics.

Attributes

Attributes of <address>
AttributeRole
idUniquely identifies the address block.

Example

<address>
  Contact: <a href="mailto:info@example.com">info@example.com</a>
</address>
Contact: info@example.com
