List Tags

<ul>

Definition

Defines an unordered (bulleted) list. It must contain one or more <li> items.

Attributes

Attributes of <ul>
AttributeRole
idUniquely identifies the list.
classApplies a CSS class to style the list.

Example

<ul>
  <li>Milk</li>
  <li>Bread</li>
  <li>Eggs</li>
</ul>
  • Milk
  • Bread
  • Eggs

<ol>

Definition

Defines an ordered (numbered) list. Items are automatically numbered by the browser.

Attributes

Attributes of <ol>
AttributeRole
startSets the number the list should begin counting from.
reversedReverses the numbering order (counts down).
typeSets the numbering style: 1, A, a, I, or i.

Example

<ol start="3">
  <li>Preheat the oven</li>
  <li>Mix the batter</li>
  <li>Bake for 30 minutes</li>
</ol>
  1. Preheat the oven
  2. Mix the batter
  3. Bake for 30 minutes

<li>

Definition

Represents a single item inside a <ul> or <ol> list.

Attributes

Attributes of <li>
AttributeRole
valueInside an <ol>, sets the number for that specific item.

Example

<ol>
  <li value="10">Jumps to 10</li>
  <li>Continues at 11</li>
</ol>
  1. Jumps to 10
  2. Continues at 11

<dl>

Definition

Defines a description list, used to group terms with their descriptions.

Attributes

Attributes of <dl>
AttributeRole
idUniquely identifies the list.
classApplies a CSS class to style the list.

Example

<dl>
  <dt>HTML</dt>
  <dd>A markup language for structuring web pages.</dd>
</dl>
HTML
A markup language for structuring web pages.

<dt>

Definition

Represents a term or name inside a <dl> description list.

Attributes

Attributes of <dt>
AttributeRole
idUniquely identifies the term.

Example

<dl>
  <dt>CSS</dt>
  <dd>A language for styling HTML.</dd>
</dl>
CSS
A language for styling HTML.

<dd>

Definition

Provides the description or definition for the preceding <dt> term.

Attributes

Attributes of <dd>
AttributeRole
idUniquely identifies the description.

Example

<dl>
  <dt>JS</dt>
  <dd>A programming language for interactivity.</dd>
</dl>
JS
A programming language for interactivity.
