Form Tags

<form>

Definition

The container element for a set of interactive controls used to collect and submit user input.

Attributes

Attributes of <form>
AttributeRole
actionThe URL that will process the submitted form data.
methodThe HTTP method used to send the data (get or post).

Example

<form action="/submit" method="post">
  ...
</form>

Form fields would appear here.

<input>

Definition

A versatile, self-closing field that lets the user enter data. The type attribute controls what kind of control is shown (text, checkbox, date, etc.).

Attributes

Attributes of <input>
AttributeRole
typeSets the kind of control, e.g. text, email, checkbox, date.
nameIdentifies the field when the form data is submitted.
placeholderShows hint text inside the field before the user types.
requiredMarks the field as mandatory before the form can be submitted.

Example

<input type="text" name="username" placeholder="Enter your name" required>

<label>

Definition

Provides a caption for a form control. Clicking the label focuses or activates its associated input.

Attributes

Attributes of <label>
AttributeRole
forConnects the label to an input by matching the input's id.

Example

<label for="email">Email:</label>
<input type="email" id="email" name="email">

<textarea>

Definition

Creates a multi-line plain-text input control, useful for comments or longer messages.

Attributes

Attributes of <textarea>
AttributeRole
rowsSets the visible number of text lines.
colsSets the visible width in characters.

Example

<textarea rows="3" cols="30">Type your message here...</textarea>

<select>

Definition

Creates a drop-down list of choices, built from a set of <option> elements.

Attributes

Attributes of <select>
AttributeRole
nameIdentifies the selected value when the form is submitted.
multipleAllows more than one option to be selected at once.

Example

<select name="fruit">
  <option value="apple">Apple</option>
  <option value="banana">Banana</option>
</select>

<option>

Definition

Defines a single choice inside a <select> drop-down or a <datalist>.

Attributes

Attributes of <option>
AttributeRole
valueThe data sent to the server when this option is chosen.
selectedMarks this option as chosen by default.

Example

<select name="size">
  <option value="s">Small</option>
  <option value="m" selected>Medium</option>
</select>

<button>

Definition

Creates a clickable button, commonly used to submit or reset a form, or to run custom scripts.

Attributes

Attributes of <button>
AttributeRole
typeSets the button's behavior: submit, reset, or button.
disabledPrevents the button from being clicked.

Example

<button type="submit">Send</button>

<fieldset>

Definition

Groups related form controls together inside a labeled box, improving structure and accessibility.

Attributes

Attributes of <fieldset>
AttributeRole
disabledDisables every control inside the fieldset.

Example

<fieldset>
  <legend>Contact Info</legend>
  <input type="text" placeholder="Name">
</fieldset>
Contact Info

<legend>

Definition

Provides a caption for the parent <fieldset>, describing what the grouped controls are for.

Attributes

Attributes of <legend>
AttributeRole
idUniquely identifies the legend.

Example

<fieldset>
  <legend>Payment Details</legend>
</fieldset>
Payment Details

<datalist>

Definition

Provides a list of predefined suggestions for an associated <input>, shown as autocomplete options.

Attributes

Attributes of <datalist>
AttributeRole
idReferenced by an input's list attribute to link the suggestions.

Example

<input list="browsers" name="browser">
<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
</datalist>
