Media Tags

<img>

Definition

Embeds an image into the page. It is a void (self-closing) element.

Attributes

Attributes of <img>
AttributeRole
srcThe URL or path of the image file to display.
altDescribes the image for screen readers and shows if the image fails to load.
widthSets the display width of the image in pixels.
heightSets the display height of the image in pixels.

Example

<img src="logo.png" alt="Site logo" width="120">

<audio>

Definition

Embeds a sound clip with built-in playback controls, using one or more <source> elements.

Attributes

Attributes of <audio>
AttributeRole
controlsShows the browser's built-in play/pause/volume controls.
autoplayStarts playback automatically when the page loads.
loopRestarts the audio automatically after it ends.

Example

<audio controls>
  <source src="song.mp3" type="audio/mpeg">
</audio>

<video>

Definition

Embeds a video clip with playback controls, using one or more <source> elements.

Attributes

Attributes of <video>
AttributeRole
controlsShows the browser's built-in play/pause/volume controls.
widthSets the display width of the video in pixels.
posterAn image shown before the video starts playing.

Example

<video controls width="250">
  <source src="movie.mp4" type="video/mp4">
</video>

<source>

Definition

Specifies one media file for its parent <audio>, <video> or <picture> element, allowing several formats to be offered.

Attributes

Attributes of <source>
AttributeRole
srcThe URL of the media file.
typeThe MIME type of the file, so the browser can pick a supported one.

Example

<video controls>
  <source src="movie.webm" type="video/webm">
  <source src="movie.mp4" type="video/mp4">
</video>

See the <video> example above — it uses <source> internally.

<figure>

Definition

Groups an image (or other media) together with its caption as one self-contained unit.

Attributes

Attributes of <figure>
AttributeRole
idUniquely identifies the figure.
classApplies a CSS class for styling.

Example

<figure>
  <img src="cat.jpg" alt="A cat">
  <figcaption>A curious cat</figcaption>
</figure>

<figcaption>

Definition

Provides a caption describing the contents of its parent <figure>.

Attributes

Attributes of <figcaption>
AttributeRole
idUniquely identifies the caption.

Example

<figure>
  <img src="chart.png" alt="Sales chart">
  <figcaption>Fig. 1 – Quarterly sales</figcaption>
</figure>

<picture>

Definition

Wraps multiple <source> elements and a fallback <img>, letting the browser pick the best image for the screen size or format.

Attributes

Attributes of <picture>
AttributeRole
idUniquely identifies the picture element.

Example

<picture>
  <source srcset="large.jpg" media="(min-width: 600px)">
  <img src="small.jpg" alt="Responsive image">
</picture>

<track>

Definition

Specifies timed text tracks, such as subtitles or captions, for an <audio> or <video> element.

Attributes

Attributes of <track>
AttributeRole
srcThe URL of the subtitle/caption file (usually .vtt).
kindThe type of track: subtitles, captions, descriptions, etc.
srclangThe language of the track text, e.g. "en".

Example

<video controls>
  <source src="movie.mp4" type="video/mp4">
  <track src="subs-en.vtt" kind="subtitles" srclang="en" label="English">
</video>

See the <video> example above — <track> adds subtitles to it.
